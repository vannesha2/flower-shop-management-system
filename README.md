# 🌷 Flower Shop Management System

A simple console-based flower shop management system developed using C++. This project was created as part of a university assignment during Semester 3 to practice fundamental programming concepts, searching algorithms, sorting algorithms, and stack data structures.

## ✨ Features

- **Add Flowers** — Store flower names, types, stock quantities, and prices.
- **Display Flower List** — View all flower records stored in the program.
- **Search Flowers** — Find flowers by name using Linear Search.
- **Sort by Price** — Sort flower records by price using Bubble Sort.
- **Undo Last Addition** — Use a Stack data structure to manage undo operations.
- **Interactive Menu** — Navigate through the program using a simple terminal-based menu.

## 🛠️ Technologies & Concepts

- **Language:** C++
- **Data Structures:** Array, Stack, and Struct
- **Algorithms:** Linear Search and Bubble Sort
- **Concepts:** Functions, Loops, Conditional Statements, and User Input Handling

## 🎯 Project Objectives

- Practice fundamental C++ programming.
- Understand how arrays and structures store data.
- Implement searching and sorting algorithms.
- Explore the use of a stack for undo functionality.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Compile the source code using a C++ compiler:

   ```bash
   g++ "toko bunga.cpp" -o toko-bunga
   ```

4. Run the compiled program:

   **Windows:**
   ```bash
   toko-bunga.exe
   ```

   **Linux / macOS:**
   ```bash
   ./toko-bunga
   ```
